# Проверка Яндекс-входа — 0.1.1

8 октября 2026. Зарегистрированный публичный Client ID подключён. Это проверка кода и локальной сборки; успешный вход с реальным аккаунтом, реальные права и облачное восстановление ещё не подтверждены.

## Пройденные проверки

- 50 JVM tests без ошибок: прежние 46 и четыре дополнительных теста подключения. Проверяются совпадение Client ID/UID, различение недостаточных прав Диска и папки приложения, канонический адрес `/v1/disk`, только GET при подключении.
- Debug APK и instrumentation APK собраны; `lintDebug` завершился без ошибок. Исправлен сбой AGP/Kotlin UAST при чтении свойств LoginSDK через Java-адаптер; lint checks не отключались.
- 7 Android tests на отдельном API 35 emulator: три прежних проверки POS и четыре проверки Keystore/session. Результат `OK (7 tests)`, 7.545 секунды.
- Session tests: перезапуск хранилища сохраняет данные, ciphertext не содержит токен, каждое сохранение получает новый nonce; повреждение ciphertext и потеря ключа отвергаются. Контроллер после попытки входа в другой аккаунт сохраняет прежние UID и credential; явное отключение удаляет локальное подключение.
- Четыре Kotlin POS fixtures независимо восстановлены Python decoder, точные байты и SHA-256 совпали.
- SHA-256 сертификата локального APK совпадает с регистрационными данными в `YANDEX_SETUP_RU.md`. CI APK подписывается другим debug-сертификатом.

APK установлен только на `Ciel_Vitrine_Test`, без подключения пользовательского облака. Новый экран подключения проверен визуально. Production token не получен и не запрашивался в чате; тесты используют синтетические credentials и отдельные временные ключи/файлы.

## Границы этого этапа

Успешный LoginSDK callback ещё не означает подключённый Диск: APK отдельно проверяет Яндекс ID, API сведений о Диске и чтение `app:/`. Токен сохраняется только после всех проверок. Недоступность сети, истечение доступа, неизвестная идентичность и отказ API не дают CONNECTED.

Фактические OAuth scopes проверятся при входе на устройстве. Если `resource_id` корня отсутствует, это не доказывает долговечную root identity. Production root binding, durable jobs, окончательный original format, реальный cloud readback и destructive preflight остаются следующими этапами. Облачная загрузка, Free Up и Trash в APK не включены.
