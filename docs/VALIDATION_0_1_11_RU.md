# Проверка 0.1.11 — 31 октября 2026

Проверена версия с облачными значками, отдельными действиями сохранения и
освобождения устройства, холодным архивом и рабочей копией. Испытания удаления
выполнялись только на собственном синтетическом JPEG в отдельном эмуляторе.
Личные оригиналы не удалялись.

| Проверка | Фактический результат |
|---|---|
| JVM | 168 методов: 165 прошли, 3 пропущены, 0 ошибок |
| Android API 35 | 66 методов: 63 прошли, 3 реальных облачных теста пропущены; 76,083 с |
| Отдельная проверка Android-удаления | Отмена и подтверждение системного запроса; облачные копии, миниатюра и привязка остаются; 2 теста прошли |
| Повреждение | Порча рабочей облачной копии, пакета фрагментов и изменение исходника блокируют запрос удаления |
| Хранилище | Аддитивная миграция SQLite v1 → v2, старые записи вне первой страницы, повторное использование рабочей копии, защита ревизии и повторное открытие |
| Интерфейс | Переходы значков, нажатие на статус отдельно от открытия фотографии |
| Независимое восстановление | 4 POS v1 и 10 CVPOS2/3 фикстур восстановлены Python-декодерами |
| Сборка с локальным OAuth | APK, тестовый APK и lint прошли; 4 мин 13 с |
| Публичная сборка без OAuth | APK и lint прошли; 1 мин 32 с |
| Android lint | 0 ошибок, 65 предупреждений; проверки не отключались |

Три JVM-пропуска относятся к недоступным POSIX-правам, созданию symlink без
привилегий на Windows и отдельному ограниченному стенду настоящего ENOSPC.
Они не считаются успешными проверками этих условий. Три Android-пропуска
относятся к реальному облаку, которое требует отдельного явного запуска.

Проверка перед системным запросом заново читает оба оригинала, пакеты
фрагментов и локальный источник. Просмотр миниатюры проверяется настоящим
расшифрованием и декодированием; видео требует доступного нативного декодера.
Это не физический замер HDR-дисплея и не новый benchmark Яндекс Диска.

После успешного удаления только тестовой строки первоначальная очистка теста
повторно обращалась к уже удалённой строке и получала SecurityException. Очистка
исправлена: она проверяет наличие строки. Затем прошли отдельный сценарий и
полный Android-набор. Предыдущие неуспешные запуски не засчитываются.

Android не предоставляет атомарное удаление с условием совпадения SHA-256 во
время открытой системной формы. Автоматическая полнота Live Photo/sidecar,
восстановление каталога после переустановки и облачная корзина не подтверждены.
