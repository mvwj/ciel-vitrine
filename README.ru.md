# Небесная витрина

Android-галерея с проверяемым хранением оригиналов в вашем облаке. Тёмная лента
по дням, небольшие локальные миниатюры и подгрузка при просмотре. Первая
интеграция — Яндекс Диск; одновременно подключено одно облако. Google Drive
запланирован.

**Экспериментальная версия.** Хранение оригинала, просмотр и удаление имеют
разные проверки. Для испытаний сохраняйте независимую резервную копию.

## Основные возможности

- Лента с датами, квадратными миниатюрами и небольшими зазорами, прокрутка по
  датам с тактильным откликом, папки, локальные альбомы и избранное.
- Значки облака на миниатюрах и этапы очереди: ожидание, подготовка, загрузка,
  проверка, холодный архив, рабочая копия, остановка или ошибка.
- Побайтовое сохранение исходника, полное обратное чтение, SHA-256 и запись
  наблюдаемых исходных дат. Создание миниатюр не меняет оригинал.
- Подгрузка видимых зашифрованных фрагментов подготовленных JPEG/PNG.
- Видеоплеер Media3 с перемоткой и чтением проверенных частей оригинала.
  Подготовленные уменьшенные SDR-версии хранятся отдельно.
- Независимое восстановление контейнеров Python/JVM-инструментами без приложения.

## Две кнопки сохранения

**«Загрузить и оставить на устройстве»**: сначала проверенный холодный архив,
затем отдельная рабочая копия Gallery Store. Исходник остаётся на телефоне.

**«Загрузить и освободить место»**: те же две копии, готовый просмотр из облака,
постоянная миниатюра, подтверждённая пользователем полнота набора, повторное
полное чтение обеих облачных копий и исходника, затем системное подтверждение
Android. Фоновые задачи не удаляют исходники.

Освобождение требует Android 11+ и поддерживаемого маршрута просмотра. Это
окончательное локальное удаление, а не корзина на 60 дней. Во время открытого
системного диалога Android не блокирует внешнее редактирование файла.
[Подробные условия и ограничения](docs/CLOUD_STATUS_AND_LOCAL_RELEASE_RU.md).

## Приватность

**Ключ восстановления находится внутри контейнера оригинала.** Облако или любой
обладатель файла технически может восстановить оригинал вместе с EXIF/GPS.
Такой формат выбран для восстановления без отдельного ключа; расширение `.bin` или `.cv2`
не скрывает данные от провайдера.

OAuth-токен и локальные каталоги защищены отдельно через Android Keystore.
В публичных исходниках нет регистрации OAuth владельца, его ключей подписи,
облачной сессии или медиатеки. [Политика безопасности](SECURITY.md).

## Сборка

JDK 17+, Android SDK 36, Build Tools 36.0.0, NDK 28.2.13676358, CMake 3.22.1.
Настройте `ANDROID_HOME` либо игнорируемый `local.properties`.

```sh
python -m pip install -r requirements-recovery.txt
./gradlew test :app:assembleDebug :app:lintDebug
python scripts/test_pos_fixtures.py
python scripts/test_pos2_fixtures.py
```

В Windows используйте `gradlew.bat` или [скрипт сборки](scripts/build-local.ps1).
APK: `app/build/outputs/apk/debug/app-debug.apk`.

Публичная сборка работает как локальная галерея. Для Яндекса скопируйте
`oauth.properties.example` в игнорируемый `oauth.properties` и настройте
собственный Client ID и сертификат по [инструкции](docs/YANDEX_SETUP_RU.md).
Client Secret в Android не используется. Сборка CI имеет другой debug-сертификат
и не подключена к регистрации владельца.

## Что ещё ограничено

Автоматическая связка Live Photo/sidecar и восстановление полного каталога после
переустановки не закончены. Неподдерживаемые форматы остаются на устройстве.
Облачное удаление и облачная корзина пока не включены. Две копии на одном
провайдере не защищают от потери всего аккаунта.

У multipart-оригиналов нет лимита допуска 128 МиБ. Подготовка фрагментов целого
фото использует отдельный кэш 256 МиБ. HDR-просмотр зависит от устройства;
уменьшение качества HDR пока отключено.

Тесты подтверждают перечисленные сценарии и образцы. Они не дают абсолютной
гарантии сохранности при любых обстоятельствах.
